VOCMAN AI Concierge
Enterprise Voice-Enabled Chatbot Widget
A high-performance, single-file AI chatbot solution custom-built for VOCMAN Pvt. Ltd. This widget blends modern "Glassmorphism" aesthetics with powerful Web Speech APIs to provide a multimodal support experience.

🌟 Key Features
Multimodal Interaction: Supports both manual text input and Voice-to-Text via a built-in microphone button.

Audio Responses: Integrated Text-to-Speech engine with a professional voice profile to read bot answers aloud.

Enterprise Knowledge Base: Pre-configured with the 10 most critical business inquiries for VOCMAN (GIS, AI/ML, Cloud, and Software Dev).

Modern UI/UX: Responsive mobile-first design featuring smooth CSS animations and the official VOCMAN blue branding.

Zero Latency: Built with lightweight Vanilla JavaScript—no external frameworks or backend required.

🛠️ Technical Architecture
The project utilizes a modular frontend architecture to ensure easy embedding into any existing web infrastructure:

Language: HTML5, CSS3, JavaScript (ES6+).

Voice Engine: webkitSpeechRecognition for input and speechSynthesis for output.

State Management: localStorage for persistent chat sessions across page refreshes.

Icons: Scalable Vector Graphics (SVG) via Font Awesome.

🚀 Deployment & Installation
1. Direct Embed
Simply paste the single-file source code into the footer of your official website template:

HTML
<link rel="stylesheet" href="vocman-bot.css">
<script src="vocman-bot.js"></script>
2. Local Development
Clone the repository and open index.html in a modern browser:

Bash
git clone https://github.com/your-username/vocman-chatbot.git
cd vocman-chatbot
open index.html
